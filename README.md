# PDF Szerkesztő – letöltés

Egyszerű, ingyenes Windows-program PDF-ek szerkesztéséhez (szövegfelismerés, átírás, aláírás).

## Telepítés

1. Nyisd meg a **[legfrissebb kiadást](https://github.com/karsaibence/pdf-szerkeszto-kiadasok/releases/latest)**.
2. Töltsd le a `PDF-Szerkeszto-Setup-x.y.z.exe` fájlt, és indítsd el.
3. Ha a Windows figyelmeztet („A Windows megvédte a számítógépet”): **További információ → Futtatás mindenképp**.

A program magától frissül, ha új verzió jelenik meg.

Ez a tároló csak a telepítőket tartalmazza.
